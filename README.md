# ChatBot - Talento Tech

Este repositorio contiene el código fuente de un asistente virtual interactivo desarrollado como parte del programa de formación **Talento Tech**. La aplicación ha sido construida utilizando el lenguaje de programación **Python** y el framework **Streamlit** para la gestión de la interfaz de usuario.

## Especificaciones Técnicas

El proyecto se centra en la implementación de un chatbot funcional, priorizando la claridad del código y la facilidad de despliegue en entornos web.

### Tecnologías y Herramientas

* **Lenguaje de programación:** Python.
* **Framework de interfaz:** Streamlit.
* **Entorno de desarrollo:** Configuración compatible con DevContainers.
* **Gestión de dependencias:** Pip.
